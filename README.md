# Nexora

Кроссплатформенное мобильное приложение для торговли криптовалютами. Android и iOS.

---

## О проекте

Nexora — мобильный клиент для отслеживания портфеля, управления торговыми ботами и выполнения сделок на криптовалютных биржах. Приложение предоставляет удобный интерфейс для мониторинга цен, анализа графиков и управления активами.

Текущий статус: интерфейс и архитектура готовы к продакшену. Рыночные данные, портфель и исполнение ордеров пока работают на демо-данных — подключение к API бирж в процессе.

---

## Возможности

- Обзор рынка с графиками цен и лентой активов
- Портфель с отслеживанием реализованного PnL и открытых позиций
- Создание и управление grid-ботами (режим paper trading)
- История торговли: ордера, исполнения, позиции
- Конфигурация бэктестов для проверки стратегий
- Подключение API бирж (Binance, Bybit, OKX)
- Push-уведомления (поддержка runtime-разрешений Android 13+)
- 8 цветовых тем с раздельными палитрами для тёмного и светлого режимов
- Настройка акцентного цвета и переключение тёмной/светлой темы
- Локализация: русский, английский, украинский

## Быстрый старт

### Требования

- Flutter SDK 3.0.0+
- Dart SDK 3.0.0+
- Android Studio с Android SDK 21+ или Xcode 14+ (для iOS, только macOS)

### Установка

```bash
git clone https://github.com/exunars/Moblie-Nexora.git
cd Moblie-Nexora
flutter pub get
```

### Запуск

```bash
flutter run
```

### Сборка

```bash
# Android APK
flutter build apk --release

# Android App Bundle (Google Play)
flutter build appbundle --release

# iOS (только macOS)
flutter build ipa --release
```

CI: в `codemagic.yaml` настроен workflow для сборки unsigned IPA (установка через Sideloadly без платного Apple Developer аккаунта).

```

  models/                      — Order, Portfolio, TradeData

    chart_screen.dart          — торговый график
    history_overview_screen.dart — ордера, исполнения, позиции
    backtests_screen.dart      — конфигурация бэктеста
    account_section_screen.dart — биржи, подписка, помощь
```

Боковое меню: Обзор, Боты, История, Бэктесты, Биржи, Подписка, Настройки, Помощь.

## Система тем

Каждый из 8 пресетов содержит раздельные палитры для тёмного и светлого режимов:

| Пресет | Акцент | Описание |
|--------|--------|----------|
| Полночь | фиолетовый | глубокий премиальный тёмный |
| Океан | бирюзовый | тёмно-синий, технологичный |
| Лес | лаймовый | изумрудный, ассоциация с ростом |
| Закат | оранжевый | тёплый графитовый |
| Ягода | розовый | тёмная слива |
| Арктика | голубой | холодный индиго |
| Светлая | фиолетовый | воздушная, современная |
| Песок | оранжевый | тёплый крем |

Переключение тёмный/светлый работает с любым выбранным пресетом. Настройки сохраняются между запусками.

## Push-уведомления

Разрешения в `AndroidManifest.xml`:
- `POST_NOTIFICATIONS` — запрашивается в runtime на Android 13+
- `RECEIVE_BOOT_COMPLETED`, `VIBRATE`

Тестовая кнопка в разделе Настройки > Отладка. Если разрешение отклонено — отображается уведомление об ошибке.

## Текущие ограничения

- Рыночные данные, портфель и ордера работают на демо-данных в памяти
- Подключение к бирже переключает локальный статус, реального API пока нет
- График использует статические точки
- iOS-проект не сгенерирован в этом checkout (требуется macOS)
- Android release использует debug-подпись
